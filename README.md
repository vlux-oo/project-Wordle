# project-Wordle
игра Wordle
игра, в которой пользователю нужно угадать слово за 6 попыток
есть 3 режима: слово из 4 букв, слово из 5 букв, слово из 6 букв, 
при угадывании(не угадывании) можно сразу сыграть еще раз, нажав кнопку "Да!" снизу в конце игры
выйти из программы можно нажав кнопку "Нет!" снизу в конце игры
